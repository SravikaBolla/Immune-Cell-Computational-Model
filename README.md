# T-Cell-Cancer Cell Interactions Agent-Based Model
This project simulates T-cell behavior/motility and interactions with cancer cells in different immune microenvironments using NetLogo. The model explores how single-cell motility parameters such as movement and turning probability affect immune surveillance and tumor targeting.
